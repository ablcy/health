# 健康顾问 - Personal Health Advisor

基于国际权威机构标准（WHO、CDC、USDA、哈佛医学院、中国营养学会）的个性化健康建议工具。

## 功能

- 输入性别、年龄、身高、体重、健康目标
- 自动计算 BMI（身体质量指数）
- 基于 Mifflin-St Jeor 公式计算基础代谢率（BMR）
- 生成个性化一周食谱计划（含热量/蛋白质/碳水/脂肪）
- 运动建议与睡眠建议
- 中英文双语切换
- 深色/浅色主题切换

## 健康目标

- 保持健康
- 保持身材
- 减肥
- 增肌
- 提升体能

## 技术栈

- 纯 HTML / CSS / JavaScript
- 前端单页应用，无需后端
